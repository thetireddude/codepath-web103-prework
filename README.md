# WEB103 Prework - *Creatorverse*

Submitted by: ***Omar Alim Mohamed***

About this web app: 

*Creatorverse is a simple web app for managing creator profiles: browse the list, add new creators, edit details, and view individual profiles in an easy, user-friendly interface. It saves and syncs data with Supabase so your creators are stored online and available across devices.*

Time spent: *~25 hours*

## Notes

This was project was done entirely without the use of AI for vibecoding. Significant challenges included migrating to a Vite environment from previous Next.js experience, and learning and then implementing react-router for the first time. A comprehensive approach was taken that involved planning the HTML layout for ease of CSS flexbox styling, implementing core backend CRUD functionality, and finally styling the components and pages. Browser devtools were used extensively to debug & polish CSS styling, and test out different screen sizes.
